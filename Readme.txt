■このゲームについて

　2Dシューティングゲーム



■起動方法

 フォルダ内の「ShoothingRemake.exe」を実行してください



■基本操作方法

 "Aキー"or"←キー"：左移動・ゲーム終了確認の選択肢変更

 "Dキー"or"→キー"：右移動・ゲーム終了確認の選択肢変更

 "Wキー"or"↑キー"：上移動

 "Sキー"or"↓キー"：下移動

 "Zキー"：弾発射

 "Spaceキー"：弾発射 + シーン遷移の決定

 "Pキー"：一時停止 + 一時停止からの再開

 "Escapeキー"：ゲーム終了確認画面の有効化

 "Enterキー"：ゲーム終了確認画面時の決定



■このゲームの独自機能 (!!ここ大事!!)


 □ゲーム内の新要素・変更要素

　・ゲームオーバーシーン実装
　　↳ 遷移条件：プレイヤーHPが０になる

　・ゲームオーバーシーン遷移後の再度ゲームを再度開始化

　・ゲームクリアシーン実装
　　↳ 遷移条件：ボスのHPを０にする

　・ゲームのフレームレートを制限(デフォルト：60fps)

　・二つのオブジェクトの衝突判定を"GetCollisions"関数に統合

　・ヒットストップ処理を"SetHitPerform()"関数に統合

　・雑魚敵をある程度撃破すると [ボス出現 + 雑魚敵生成無効化]

　・プレイヤー・雑魚敵・ボス敵の"SetIsAlive()"関数と"SetHP()"関数を"Damage()"関数に統合


 □プレイヤーの新要素・変更要素

　・プレイヤー移動操作を"PlayerMove"関数に統合

　・移動を"WASD操作"と"矢印操作"の両立 (同一操作キー入力時の二重移動は無効)

　・弾発射処理を"Zキー"と"Spaceキー"の両立

　・"Pキー"で一時停止・再度入力で再開

　・キー入力の押下・解放判定をクラス化し関数化

　・弾発射判定と弾再生成を"GetIsShotActive"関数に統合

　・ボス出現時で一定の縦位置にいるとき [縦移動手動無効 + 縦自動移動 + 縦移動可能領域 変更]


 □雑魚敵の新要素・変更要素

　・雑魚敵がプレイヤーを横移動追尾 (画面中心で追尾速度が半減)

　・HP実装(数回攻撃で撃墜可能)

　・弾で雑魚敵を攻撃した時の判定

　 → ＨＰが０ではない時は "被ダメ演出"

　 → ＨＰが０の時は "撃破演出"


 ※ 撃破演出： 画面揺らし
		爆発演出
	 	ヒットストップ

 ※ 被ダメ演出：爆発演出
		 短めのヒットストップ
		 敵の移動速度減少
		 HPバーの値減少


 □ボス要素

　・出現条件：雑魚敵をある程度倒す

　・出現時・被ダメ後の無敵状態中は 攻撃無効化

　・ボス被ダメ時：弾の衝突位置に爆発演出を発生
		   一時的な無敵を付与

　・無敵状態時は弾を消滅し、攻撃を無効化する

　・弾でボス敵を攻撃した時の判定

　 → ＨＰが０ではない時は "被ダメ演出"

　 → ＨＰが０の時は "撃破演出"


 □UI系

　・一時停止時にUIを描画

　・ゲーム終了確認時にUIを描画
　　↳ 未選択の"YES"もしくは"NO"は半透明で描画

　・フレームレートを描画(第1小数点まで表示)

  ・プレイヤーにHPバー実装(HP減少時にバーがHPの割合で変動)

  ・雑魚敵にHPバー実装(HP減少時にバーがHPの割合で変動)

  ・ボス敵にHPバー実装(HP減少時にバーがHPの割合で変動)


 □その他新要素・変更要素

  ・プレイヤーのHPバーを追加するためにゲーム画面範囲拡大

　・スクリプトを"Script"フォルダに集約

　・分かりづらいマジックナンバーを定数に変更

　・main.cppの未使用領域以外の全処理にコメントを追加
